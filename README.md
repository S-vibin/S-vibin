# Portfolio

A lightweight GitHub Pages portfolio is available on the branch `add-portfolio-site`.

Preview the branch here: https://github.com/S-vibin/S-vibin/tree/add-portfolio-site

To publish the site on GitHub Pages:
1. Go to Settings → Pages
2. Under 'Build and deployment' select 'Branch' and choose `add-portfolio-site` (or merge the branch into `main`).
3. Save — the site will be available at `https://S-vibin.github.io/S-vibin/` (may take a minute).

If you want, I can open a PR from `add-portfolio-site` to `main` and help you publish it.
